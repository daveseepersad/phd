Abstract
This technical report describes Agent Brain, a biologically inspired memory system for autonomous AI agents.
In contrast to stateless Large Language Model interactions, Agent Brain provides persistent, weighted, and
self-organizing memory that emulates human cognitive processes: perception, storage, retrieval,
consolidation, and forgetting.
The system integrates eleven successive layers: (1) a Perception Gate for multi-dimensional evaluation of
incoming information, (2) a Deduplication Guard based on Cosine Similarity, (3) typed memory storage
(episodic, semantic, procedural), (4) Named Entity Recognition using flair/ner-german-large (F1 92.31%), (5) a
Knowledge Graph for associative retrieval, (6) LLM-based Query Expansion, (7) Hybrid Search via Reciprocal
Rank Fusion, (8) Cross-Encoder Re-Ranking for precise relevance assessment, (9) an implicit Feedback Loop

1.2 Contributions
This paper presents Agent Brain, a memory system that makes the following novel contributions:
1. Implicit Feedback Loop: Automatic reinforcement and attenuation of memories based on embedding
comparisons between retrieval and storage operations — without any manual user feedback.
2. FSRS for Agent Memory: First-time application of the Free Spaced Repetition Scheduler (Ye, 2024) to
autonomous agent memories rather than flashcards.
3. Multi-Stage Dream Cycle: A biologically inspired nightly consolidation process with five phases: decay,
consolidation, creative association formation, pattern recognition, and predictive warnings.
4. LLM-Based Query Expansion: Intelligent expansion of colloquial search queries with domain-specific
technical terminology through a dedicated LLM call.

2. Related Work
2.1 LLM Memory Systems
Mem0 (Mem0.ai, 2024) provides persistent memory for LLM applications with automatic extraction and
organization of facts from conversations. It uses graph-based storage but offers neither Spaced Repetition nor
a consolidation mechanism. Furthermore, it lacks a domain-specific NER component.
Zep (Getzep, 2024) implements a Memory Server with embedding-based search and Knowledge Graph
extraction. Zep offers Hybrid Search but has no feedback mechanism that adjusts the weighting of memories
based on actual usage.
MemGPT (Packer et al., 2023) proposes a virtual context management approach modeled after hierarchical
memory systems of operating systems. The approach focuses on context window management within a
session, not on long-term memory weighting across sessions.
LangChain Memory (LangChain, 2023) offers various memory types (Buffer, Summary, Entity Memory) as
part of the LangChain framework. The implementations are functional but lack any mechanism for temporal
decay or usage-based reinforcement.

2.2 Spaced Repetition
The Free Spaced Repetition Scheduler (FSRS) (Ye, 2024) is an evidence-based algorithm for optimal
flashcard management built on the DSR model (Difficulty, Stability, Retrievability). FSRS has so far been used
exclusively for human learning with flashcards. The present work transfers FSRS for the first time to
autonomous agent memories.
2.3 Named Entity Recognition for German
flair (Akbik et al., 2019) is an NLP framework with pre-trained sequence tagging models. The model ner-
german-large is based on XLM-RoBERTa-large and achieves an F1 score of 92.31% on the CoNLL-03 German
Benchmark. This is particularly relevant for the Swiss property domain, as specific company names (e.g.,
“Immo Treuhand AG”, “Betreibungsamt Luzern” [debt collection office]) must be correctly recognized as
organizations.
2.4 Hybrid Search
Reciprocal Rank Fusion (RRF) (Cormack, Clarke & Büttcher, 2009) combines rankings from different search
systems into a unified result. The method is robust against different score scales and requires no
normalization of input rankings.
2.5 Multi-Memory Systems for Agents
Wang et al. (2012) present in “A Self-Organizing Multi-Memory System for Autonomous Agents” a system
with three memory types (episodic, semantic, procedural) based on Fusion Adaptive Resonance Theory (ART).
The system implements memory consolidation (transfer from episodic to semantic knowledge) and prevents
catastrophic forgetting through parallel processing across different timescales. Evaluation is conducted in a
game environment (Unreal Tournament). Agent Brain adopts the same biological tripartition of memory types
but replaces ART with FSRS-based weighting and adds Hybrid Search, Cross-Encoder Re-Ranking, and a

2.6 Brain-Inspired Memory Architectures
Yu et al. (2024) propose in “Brain-inspired AI Agent: The Way Towards AGI” a conceptual framework that
maps cortical brain regions (Hippocampus, Prefrontal Cortex, Default Mode Network) to functional agent
modules. The paper provides the theoretical foundation for brain-inspired agents but remains at the
conceptual level without practical implementation or quantitative evaluation.
Microsoft Research (Blumenthal et al., 2025) present in “A brain-inspired agentic architecture to improve
planning with LLMs” the Modular Agentic Planner (MAP), published in Nature Communications. MAP uses
brain-inspired modules (Conflict Monitoring, State Prediction, Task Decomposition) to improve LLM-based
planning. The work demonstrates significant improvements on planning tasks (Graph Traversal, Tower of
Hanoi) but focuses exclusively on planning — without memory management, spaced repetition, or
consolidation.
Agent Brain and MAP address complementary aspects of brain-inspired agent architectures: MAP optimizes
Planning (Prefrontal Cortex), Agent Brain optimizes Memory (Hippocampus + Consolidation). Agent Brain
represents — to the best of our knowledge — the first complete practical implementation of a brain-inspired
memory system, with quantitative retrieval benchmark results (P@5=0.787, MRR=0.762).

3. System Architecture
The architecture of Agent Brain comprises ten layers that cover the entire lifecycle of a piece of information.
The process is divided into three main flows: Storage (Store), Retrieval (Recall), and nightly Consolidation
(Dream Cycle).

Agent → /store → Perception Gate v2 (4-dimensional evaluation)

 → Entity + Relationship → Knowledge Graph

Phase 2: Consolidation → Cosine > 0.92 → merge
Phase 3: Creative Connections → Random Walk in Knowledge Graph
Phase 4: Pattern Recognition → Identify recurring events
Phase 5: Predictive Alerts → Seasonal + overdue warnings
Core Principle: Every memory has a weight (0.0–1.0+) that determines its survival. Memories with a weight
below 0.05 are filtered out during retrieval.

11.3 FSRS Integration
The Free Spaced Repetition Scheduler (Ye, 2024) is employed with the following power-law decay:
R = (1 + 0.2346 × elapsed_days / stability)^(−0.5)
This differs fundamentally from exponential Ebbinghaus decay: memories do not disappear suddenly but
become gradually harder to retrieve. The stability of a memory determines how long it survives.

12. Layer 9: Dream Cycle
The Dream Cycle runs daily at 02:00 and comprises five phases:
Phase 1: FSRS Decay
All memories are re-weighted according to the power-law formula (Section 11.3). Memories with high stability
(frequently retrieved, well reinforced) decay slowly; memories with low stability decay quickly.
Phase 2: Consolidation
Memory pairs with Cosine Similarity > 0.92 are merged. The memory with higher weight survives and is
enriched with the content of the other. This reduces redundancy and strengthens surviving memories.

Through random walks in the Knowledge Graph (depth 2), implicit relationships between entities are
discovered. If Entity A is connected to B and B to C, but A and C are not directly connected, a creative

15. Evaluation on LongMemEval-M
15.1 Motivation
The evaluation in §14 measured Agent Brain on our internal production workload (P@5 = 0.787 on the Valtis
property-management corpus). While informative for production readiness, internal benchmarks are not
cross-system comparable. To anchor Agent Brain against a publicly specified dataset we evaluated it on
LongMemEval (Wu et al., 2024), a public long-context memory benchmark.
LongMemEval is distributed in multiple variants. The most-reported in peer literature is LongMemEval-S
(Small); the medium variant is distributed on Hugging Face as weaviate/longmemeval-m-cleaned. This work
evaluates on the m-cleaned variant. To the best of our knowledge no peer numbers on m-cleaned were public at
the time of writing, so the cross-system ranking in this section is deliberately non-comparative.
15.2 Dataset and Methodology
We used the weaviate/longmemeval-m-cleaned variant, which contains 500 question-answer pairs derived
from 510 multi-turn conversational workspaces with an average length of approximately 115k tokens.
Ground-truth answers are provided; judging is performed by GPT-4o as a rubric-graded judge.
Ingestion pipeline (identical for all tested configurations):
1. Each workspace ingested as one user with one session.
2. Turn-level messages written to memories table via /memory/store endpoint.
3. Auto-extraction produces episodic memories, entities, and relationships.
4. Embeddings: sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2 (384 dimensions,
normalized).
5. Hybrid retrieval: vector cosine (70%) + PostgreSQL tsvector (30%), combined via Reciprocal Rank
Fusion (k = 60), top-5 returned.

15.5 Discussion of the Consolidation Regression
A surprising — and instructive — result is that enabling our Dream Cycle consolidation pipeline reduces
accuracy by 1.9 pp (71.7% → 69.8%), and that our own pgvector-only baseline without entity extraction
outperforms Brain by 2.2 pp on one run (73.9% vs 71.7%).
We interpret this as follows:
1. The Dream Cycle is too aggressive for quiz-style benchmarks. Consolidation compresses multiple
related memories into summarized representations (Phase 2 of the five-phase cycle). This preserves
meaning well for continuity-based retrieval — the workload our production system is designed for — but
removes verbatim detail that LongMemEvalʼs GPT-4o judge requires for exact factual matches (dates,
phone numbers, specific names).

2. Hybrid retrieval helps continuity but not quizzes. The 70/30 vector–tsvector split trades some exact-
match lexical recall for robustness against paraphrasing. LongMemEval rewards exact match heavily.
3. Entity-extraction overhead costs recall on single-hop questions. 95%+ of LongMemEval questions
require recalling one specific fact from one specific turn. Entity abstraction (our design for multi-hop
reasoning) adds noise to the top-5 when the question is a lookup, not a reasoning task.
We do not consider these findings a failure — they are calibration data. They indicate that our design choices
favor production workloads (multi-month conversational continuity with complex entities) over synthetic quiz
benchmarks. We are actively addressing the regression:
Dream Cycle tuning: Reducing consolidation aggressiveness, preserving high-weight episodic
memories verbatim when the Ebbinghaus decay timer is still fresh (< 30 days).
Embedding upgrade: Evaluating BAAI/bge-base-en-v1.5 (768d) and mxbai-embed-large-v1 (1024d) as
replacements for MiniLM-L12-v2 (384d). Preliminary internal runs suggest +3–5 pp on our production
corpus.
Retrieval gating: Detecting quiz-style questions (short, specific, single-entity) and routing them to a
purely lexical path, bypassing entity-level abstraction.
Target: ≥ 80% on LongMemEval-m-cleaned with Dream Cycle enabled, within one evaluation cycle (Q2 2026).
15.6 Limitations of LongMemEval as a Metric
LongMemEval measures quiz-style factual recall from long conversational context. It is the best-known
public benchmark for memory systems available today, and we take its signal seriously. However, it does not
measure:
Cross-session continuity (remembering context from a week ago in a new conversation).
Relational reasoning (connecting entities across workspaces — the strength of graph-augmented
memory).

17. Limitations
1. Domain Specificity: Query Expansion is currently tailored to Swiss property management
(Immobilienbewirtschaftung). Transferring to other domains requires new expansion rules.
2. Language Limitation: NER and full-text search are optimized for German. Multilingual support is
architecturally feasible but not implemented.
3. Production Benchmark Scope: The production benchmark dataset (20 queries, 10 topic areas) covers
the most common property management scenarios but is not standardized. §15 adds a public
measurement on LongMemEval-M-cleaned, but without comparable peer numbers on that variant cross-
system ranking remains out of reach.
4. Consolidation Regression on Quiz-Style Benchmarks: On LongMemEval-M-cleaned, enabling the Dream
Cycle reduces accuracy by 1.9 pp versus the un-consolidated Brain, and our own pgvector-only control
outperforms the full pipeline by up to 2.2 pp (see §15.5). We attribute this to over-aggressive detail
pruning and are actively tuning the consolidation phase.
5. Scaling Limits: The system runs on a single VPS with 8 GB RAM. Significantly larger data volumes would
require a distributed architecture.
6. Feedback Latency: The implicit Feedback Loop requires that storage operations occur within 30
minutes of retrieval operations. Longer work processes are not captured.

19. Conclusion
Agent Brain demonstrates that biologically inspired memory mechanisms — perceptual evaluation, typed
storage, usage-based reinforcement, temporal decay, and nightly consolidation — can be successfully
transferred to autonomous AI agents.
The central contributions are: - An implicit Feedback Loop that operates without manual user feedback. -
The first-time application of FSRS to agent memory. - A multi-stage Dream Cycle with consolidation and
creative association formation. - LLM-based Query Expansion with intelligent technical term augmentation. -
Cross-Encoder Re-Ranking for precise relevance assessment after Hybrid Search. - Quantitative
evaluation: P@5 = 0.787, MRR = 0.762, Hit Rate = 85% in the production benchmark (2,355 memories, 20
queries). - First published evaluation on LongMemEval-M-cleaned:71.7% accuracy without consolidation,
69.8% with the Dream Cycle enabled, 72.2 – 73.9% for our pgvector-only control. We transparently report
the 1.9 pp consolidation regression and the 2.2 pp gap to the control, and we deliberately abstain from cross-
system ranking because no peer numbers exist on this specific variant (§15).
The system has been in production use since early 2026 and demonstrates that weighted, self-organizing
memory enhances the performance of autonomous agents on multi-month processes. We view reproducible
benchmarking with explicit variant labels as a necessary discipline for the emerging memory-systems field and
invite the community to reproduce our m-cleaned numbers and add peer runs via the released repository.
