CodeQual-Agent: An Intelligent LLM-Agent
Framework for Automated Software Quality
Assessment with Explainable Predictions and
Real-Time Analysis
Faisal Mohammad, Junaid K. Kakar, D. R. Bekale Be Ndong, Mot Chas, and Duksan Ryu
Department of Software Engineering
Jeonbuk National University, Jeonju 54896, Republic of Korea
{mfaisal, duksan.ryu}@jbnu.ac.kr
Abstract—Software quality assurance requires scalable solutions
combining the deterministic precision of static analysis with
the contextual reasoning of semantic understanding. This paper
presents CodeQual-Agent, a hybrid neural-symbolic framework
bridging traditional metrics-based assessment with Large Lan-
guage Model (LLM) capabilities through an intelligent orchestra-
tion architecture. The framework addresses three fundamental
challenges: (1) integration of symbolic features with neural
reasoning, (2) efficient distillation of quality-assessment expertise
from high-capacity teacher models into deployable student
agents, and (3) explainable predictions that build developer trust.
CodeQual-Agent employs a Virtual SonarQube Instance as its
symbolic foundation, extracting objective metrics (cyclomatic
complexity, code duplication, maintainability indices) that serve as
attention-weighted anchors grounding LLM reasoning. Through
knowledge distillation from GPT-4 and Gemini Pro teachers
to a Gemini 2.5 Flash student, the framework achieves 94.0%
precision at 450 ms inference latency, maintaining 96.8% of
teacher accuracy while delivering a 2.6 × speedup. A Human-in-
the-Loop (HITL) active learning pipeline reduces false positives
by 17% over three update cycles. SHAP-based explainability
achieves 87% alignment with developer intuition. Evaluated on
150,000 samples across three complementary datasets, real-world
deployment demonstrates a 14% reduction in production defect
escape rates and 83% developer adoption.
Index Terms—Software Quality Assessment, Hybrid Neural-
Symbolic Systems, Knowledge Distillation, LLM Agents, Explain-
able AI, Static Analysis Integration, Active Learning, Defect
Prediction
I. I NTRODUCTION
M
ODERN software development operates at unprece-
dented scale, with distributed teams managing codebases
of millions of lines across diverse languages. Quality assurance
must therefore transcend manual code review and conventional
static analysis.
The software quality assessment landscape presents a funda-
mental tension. Symbolic approaches (SonarQube, Checkmarx,
PMD) provide deterministic, rule-based analysis but suffer
from context-blindness, producing 30–70% false positive rates
that drive developer alert fatigue [1], [2]. Neural approaches
(LLMs) demonstrate remarkable semantic understanding but
risk hallucination and operate as black boxes, limiting developer
trust. We hypothesise that synthesising these paradigms—using
symbolic metrics to ground neural reasoning while leveraging
LLM contextual understanding to overcome symbolic rigid-
ity—achieves superior performance beyond simple feature
concatenation.
This work addresses three research questions: RQ1 (Hybrid
Effectiveness): Does attention-weighted fusion of SonarQube
metrics with LLM analysis reduce false positives and false
negatives compared to pure approaches? RQ2 (Distillation
Efficiency): How effectively can quality-assessment rationales
be distilled from high-parameter teachers to lightweight stu-
dents without significant recall loss? RQ3 (Explainability and
Trust): Does SHAP-based explainability improve actionability
and developer trust compared to ungrounded LLM explana-
tions?
Contributions: (1) A hybrid neural-symbolic fusion mecha-
nism with dynamic symbolic-neural weight balance preventing
hallucination while maintaining contextual flexibility. (2) A
Teacher-Student distillation pipeline introducing rationale dis-
tillation—training the Student to replicate Teacher explanation
embeddings, preserving reasoning depth. (3) A HITL active
learning pipeline using uncertainty-based sample selection
and LoRA fine-tuning for continuous improvement. (4) An
integrated SHAP-based explainability framework with counter-
factual generation and natural language rationales.
II. R ELATED WORK
Early ML approaches (Naive Bayes, Random Forests, SVM)
predicted defect-prone modules using hand-crafted features, re-
porting AUC values of 0.70–0.85 but with limited cross-project
generalisation [3], [4]. Pre-trained code models (CodeBERT [5],
GraphCodeBERT [6], CodeT5 [7]) improved performance but
require substantial labeled data and offer limited interpretability.
Recent LLMs (GPT-4 [8], Gemini [9], Claude [10]) demon-
strate sophisticated code understanding but are typically
deployed as passive inference endpoints without structured
analysis integration. Hybrid symbolic-neural systems show
promise in narrow tasks (specific bug types, clone detection),
but comprehensive quality assessment with explainability and
production deployment remains an open problem.

Knowledge distillation [11], [12] has been applied to

reasoning depth by training students on teacher explanation

prediction in post-hoc settings; CodeQual-Agent integrates
explainability directly into the agent’s reasoning process.
III. C ODE QUAL-AGENT ARCHITECTURE
A. System Overview
Figure 1 provides the overview of the proposed architecture.
CodeQual-Agent implements a three-layer architecture: a
Symbolic F oundation (SonarQube + AST parsing), a Neural
Reasoning Core (Gemini 2.5 Flash with attention-weighted
fusion), and an Application Interface (REST API, dashboard,
CI/CD hooks). Three design principles guide the architecture:
complementary fusion (each component compensates for
the other’s weaknesses), reasoning preservation (distillation
transfers reasoning processes, not just labels), and continuous
adaptation (HITL feedback refines behaviour post-deployment).
B. Symbolic-Neural Bridge
Symbolic Foundation. A containerised SonarQube 9.9 in-
stance extracts per-file metrics including cyclomatic complexity
(CC ), cognitive complexity, duplication ratio, maintainability
index (MI = 171− 5.2 ln(HV )− 0.23CC− 16.2 ln(LOC)),
technical debt, and security hotspots (CWE/OW ASP), together
with violations across 174 built-in rules. Tree-sitter [28]
parsers provide language-agnostic AST extraction for seven
languages, serialised to compact JSON (60% token reduction).
Combined, these form a 68-dimensional hybrid feature vector
(48 quantitative metrics, 12 code smell flags, 8 contextual
features).
Attention-Weighted Fusion. Rather than treating metrics
as ordinary features, CodeQual-Agent dynamically adjusts the
symbolic-neural balance based on code complexity:

D. Human-in-the-Loop Active Learning
Developers provide per-issue feedback (confirmed bug, false
positive, severity mismatch, missing issue). A composite prior-
ity score selects the top 500 samples monthly for retraining:
Priority = 0.5H + 0.3 (1− ConfGap) + 0.2 FI Var (6)
whereH is prediction entropy, ConfGap the top-two probability
margin, and FI Var feature importance variance. LoRA [23]
(rank r = 8, 3 epochs on prioritised samples + 10% original
data) enables monthly updates at a fraction of full fine-tuning
cost. Updated models undergo A/B testing on 10% of users be-
fore full promotion (p< 0.05 required on agreement rate, FPR,
and critical recall). Over three cycles: FPR 14.3% → 11.8%
(17% reduction), agreement 82.7% → 85.2%, critical recall
89.1%→ 91.3%.
E. Integrated Explainability and SMOTE
SHAP Attribution. KernelSHAP (1,000 samples; 95%
correlation with exact values at <100 ms overhead) computes
Shapley values over the hybrid feature vector, producing
signed feature importance visualisations, counterfactual what-
if scenarios, and LLM-generated natural language rationales
grounded in feature importance.
SMOTE in Feature Space. To address severe class im-
balance (critical bugs: 2–5%), SMOTE [19] is applied to the
extracted feature vector rather than raw code (text interpolation
is semantically meaningless). A 1:3 minority-to-majority target
ratio maintains distributional realism; critical F1 improves from
0.829 (without) to 0.920 (with), and critical recall from 78.1%
to 89.6%.
IV. E XPERIMENTAL METHODOLOGY
Datasets. Three complementary corpora totalling 150,000
samples: SonarQube Metrics (90,000 samples / 60%): These
provide the quantitative baseline for static analysis, including
cyclomatic complexity, maintainability index, and common
code smells. 500 open-source Java/Python projects annotated
with SonarQube 9.9 (174 rules; severity labels Blocker–Info).
CQDataset (37,500 samples / 25%): Mined from high-star
GitHub repositories, these snippets were filtered using commit
history (focusing on ”fix” vs. ”refactor” keywords) to provide
labels for general code quality and readability. Python code
from top-1000 GitHub projects and competitive programming
platforms, annotated by automated tools (40%) and 6 expert
developers (60%; Cohen’s κ = 0.72). Defects4J v2.0(22,500
samples / 15%): A benchmark of reproducible real-world bugs
from large-scale Java projects, used as the ”Golden Standard”
for training the agent to recognize critical defect patterns [20].
835 real bugs from 17 Java projects, augmented via temporal
expansion, context expansion, and clone-detected similar code
mining; 1,000 augmented samples manually validated (91%
label agreement). Stratified 70/15/15 train/validation/test split
with project-level separation to prevent data leakage.
Baselines. (1) GPT-4 [8]: identical prompting without
orchestration; establishes accuracy ceiling (1.76T params,
1,200 ms). (2) CodeLlama [27]: 7B-parameter decoder-only
model fine-tuned on code; represents efficient instruction-tuned

LLM baselines. (3) CodeT5 [7]: 220M-parameter encoder-
decoder; represents specialised pre-trained code models. (4)
CodeBERT [5]: 125M-parameter encoder-only model with
classification head, 10 epochs, AdamW, lr 2e-5. (5) Mamba-
2.8B [22]: state-space model; continued pre-training on Code-

Metrics. Classification: Precision, Recall, and F1 (macro-

Ablations. Five variants isolate component contributions:
NoAST (removes structural features), NoSMOTE (original
imbalanced data), NoAgent (uniform preprocessing; no or-
chestration), NoXAI (removes explainability output), NoDistill
(Student trained on labels only, no Teacher rationales).

B. Ablation Studies
Table II presents the ablation results. Removing SMOTE and
agent orchestration each cause the largest equal performance
drop ( ∆F1 =−0.100), followed by knowledge distillation
(−0.060), AST integration (−0.040), while XAI removal incurs

SMOTE (−10.0% F1): without oversampling, the model
trained on the imbalanced raw defect distribution suffers a
dramatic recall collapse from 91.0% to 74.0% ( −17 points),
reducing F1 from 0.920 to 0.820 and confirming that class
balancing is essential for minority defect class coverage.
Agent Orchestration (−10.0% F1): removing symbolic
and RAG grounding reduces the system to a standard LLM,
matching SMOTE’s drop at F1 = 0.820, which confirms that
structured reasoning over static metrics is equally critical to
balanced training data.
Knowledge Distillation (−6.0% F1): training on labels alone
yields F1 = 0.860 vs. 0.920, confirming that rationale transfer
from teacher models conveys reasoning depth beyond label
matching.
AST Integration (−4.0% F1): structural code abstraction
contributes meaningfully, with impact expected to intensify on
high-complexity code (CC >15) where raw text input loses
syntactic context.
XAI Components (∆F1 = 0.000): the negligible accuracy
cost validates that SHAP explainability is incorporated without
any compromise to predictive performance.

VI. D ISCUSSION
A. Why Hybrid Outperforms Pure Approaches
Symbolic metrics eliminate “plausible but incorrect” as-
sessments common in purely neural approaches [25]: without
SonarQube grounding, the agent occasionally rates CC >20
code as maintainable. The hybrid advantage is maximal (>10%
F1 over CodeBERT and Mamba) for complex algorithms
(CC >20), security-critical code, and performance-sensitive
paths; moderate (2–4%) over instruction-tuned models like
CodeLlama and CodeT5 for standard business logic; and
minimal (<2%) for simple CRUD operations and configuration
files—suggesting adaptive deployment strategies allocating
hybrid analysis to prioritised modules.
B. Distillation and Curriculum Insights
Distillation fidelity varies by capability: high fidelity ( >95%
of Teacher) for pattern recognition and severity classification;
moderate (90–95%) for contextual judgment; low ( <90%)
for novel defect types and domain-specific best practices.
Curriculum training contributes 1.5 F1 points overall and 4.9
points on hard examples (Teacher disagreements), with faster
convergence (7 vs 10 epochs) and better generalisation (test-
train gap 0.012 vs 0.023).
LoRA [23], [24] achieves 82% of full fine-tuning benefit
(+0.018 vs +0.022 F1) at 36× faster training and with minimal
catastrophic forgetting (0.2 vs 0.9 F1 point drop), enabling a
sustainable monthly update cadence.
C. Failure Modes
Systematic weaknesses include: domain-specific idioms
(initial 23% FPR on valid NumPy patterns; reduced to 11%
after 2 HITL cycles); legacy code overwhelm ( 100+ findings
per file; mitigated by gradual rollout); concurrency complexity
(race condition recall 73% vs 91% overall, due to limited data
flow analysis and training data skew toward synchronous code);
and novel framework idioms in frameworks released within 6
months.

D. Threats to V alidity
Internal: Dataset concentration in Java/Python; inheritance
of GPT-4 biases in Teacher labels; hyperparameter sensitivity.
External: Domain specificity (general-purpose code); two de-
ployment organisations; temporal validity (2015–2024 training
data). Construct: Five quality dimensions are not exhaustive;
ground truth involves subjective expert judgment.
E. Ethical Considerations
Automation risk of atrophying developer critical thinking is
mitigated through confidence scores, explainability, and framing
the tool explicitly as advisory. Bias monitoring (FPR/FNR
stratified by code style) and third-party audits address potential
perpetuation of historical coding biases. Developers remain
accountable for committed code; organisations for deployment
configuration; and tool providers for transparency regarding
limitations.
VII. C ONCLUSION
CodeQual-Agent demonstrates that hybrid neural-symbolic
architectures, enhanced through knowledge distillation and
HITL active learning, enable practical, trustworthy automated
software quality assessment. Symbolic grounding in SonarQube
metrics constrains LLM outputs to verifiable static analysis
evidence, reducing false positives, while LLM flexibility over-
comes symbolic rigidity, achieving 94.0% precision at 450 ms
— a 2.6× speedup over GPT-4 at 96.8% relative accuracy,
and superior F1 over all non-teacher baselines including
CodeLlama (0.900), CodeT5 (0.880), Mamba (0.860), and
CodeBERT (0.800). Rationale distillation preserves reasoning
depth; uncertainty-based HITL reduces false positives 17% over
three cycles; and SHAP explainability achieves 87% developer
alignment and 4.4/5.0 likelihood-to-act ratings. Production
deployments demonstrate 14% defect escape reduction and
83% adoption, validating practical effectiveness. The hybrid-
distillation-HITL paradigm is broadly applicable to domains
combining systematic rigour with contextual judgment —
including medical diagnosis, financial analysis, and legal review.
Future work will extend coverage to additional programming
languages, multi-file architectural analysis, and automated
remediation with formal verification.
